Code-to-Analysis and Figure Mapping
===================================

Project title:
Proteomic profiling of acute postprandial responses to five single-meal challenges and implications for cardiometabolic health

Repository:
https://github.com/TZCeciliaZhang/human_diet_proteomics_acute

Purpose of this document:
This document maps each analysis script in the repository to the corresponding
data-processing step, statistical analysis, figure, table, or supplementary
analysis reported in the manuscript. The scripts are written in R and were
developed to support the processing, analysis, visualization, and interpretation
of the plasma and urinary proteomics data.

Software:
- R version: 4.3.2
- Main statistical framework: generalized estimating equations (GEE)
- Batch correction: ComBat implemented in the sva package
- Functional enrichment: Metascape
- Mendelian randomization: TwoSampleMR and MendelianRandomization
- Visualization: R-based plotting and heatmap functions

General analysis workflow:
1. Quality control and coefficient-of-variation assessment
2. Data organization and merging
3. Calculation of log2 fold changes and batch correction
4. Exploratory dimensionality reduction and temporal clustering
5. GEE-based differential protein analysis
6. Baseline phenotype analysis
7. Pathway and functional enrichment analysis
8. ASCVD-related protein visualization
9. Comparison with previously reported studies
10. Exploratory urinary proteomic pathway analysis


----------------------------------------------------------------------
1. 1diet_pool_CV.R
----------------------------------------------------------------------

Primary purpose:
Quality-control analysis of pooled proteomics data and calculation of
coefficient of variation (CV) across pooled samples or quality-control samples.

Related analyses:
- Assessment of analytical reproducibility
- Evaluation of proteomics measurement precision
- Calculation and visualization of CV distributions

Related manuscript content:
- Plasma and urine proteomics quality-control assessment
- Statement regarding the median CV of approximately 3% for plasma and 5% for
  urine proteomic data

Related figures/tables:
- Supports the quality-control results reported in Figure S1B and Figure S1C,
  where applicable.
- May also support supplementary quality-control tables, if generated.

Expected outputs:
- CV summary statistics
- CV distribution plots
- Quality-control figures for plasma and/or urine proteomic datasets

Input data:
- Pooled or quality-control proteomics data
- Sample annotation and batch information

Output files:
- CV statistics
- Quality-control plots
- Intermediate files used in subsequent batch-effect assessment

10. 8GEE.R
----------------------------------------------------------------------

Primary purpose:
Identification of differentially expressed proteins using generalized estimating
equations (GEE).

Related analyses:
- Modeling of repeated measurements within participants
- Assessment of postprandial changes over time
- Identification of differentially expressed proteins for each meal
- Application of the study criteria:
  - Benjamini–Hochberg FDR < 0.05
  - Absolute log2 fold change > 0.26

Related manuscript content:
- Primary statistical analysis of acute plasma proteomic responses
- Identification of differentially expressed proteins following:
  - High-glucose challenge/OGTT
  - Ketogenic meal
  - HFHC meal
  - NFNC meal
  - LFLC meal

Related figures/tables:
- Figure 1B: Number of differentially expressed plasma proteins at each
  postprandial time point
- Figure 1C–D: Proteins commonly altered across the five interventions
- Figure 2A–B: Between-diet proteomic comparisons
- Figure 3B: Postprandial TGM2 response
- Figure 4A–B: Baseline protein comparisons, where applicable
- Tables S2–S6: Diet-specific differentially expressed proteins

Expected outputs:
- GEE model results
- Protein-specific effect estimates
- P values and FDR-adjusted P values
- Lists of differentially expressed proteins
- Time-specific and diet-specific statistical results

Input data:
- Batch-corrected proteomic data
- Participant identifiers
- Diet and time-point information
- Baseline and postprandial sample annotations

Important reproducibility notes
----------------------------------------------------------------------

1. The scripts should be executed in the order of data preparation, quality
   control, batch correction, statistical analysis, pathway analysis, and
   visualization.

2. The expected order of analysis is:

   a. 1diet_pool_CV.R
   b. 2diet_batch_CV.R
   c. 3diet_TR_CV.R
   d. 4Merge_ratio_step1.R
   e. 4Merge_ratio_step2.R
   f. 5combat.R
   g. 5.2lgFC_combat_data.R
   h. 6UMAP.R
   i. 7mfuzz_lgFC.R
   j. 8GEE.R
   k. 9Base_CAP.R
   l. 10pathway.R
   m. 11ASCVDheatmap.R
   n. 12previous studies_dotline.R
   o. 13new studies_dotline.R
   p. 14urine_pathway.R

3. The exact order may vary depending on the input data and whether an analysis
   is being rerun from an intermediate processed dataset.

4. The primary proteomic statistical analyses used proteins detected in more
   than 80% of samples. Missing values were imputed using a sequential
   k-nearest-neighbor approach before downstream statistical analysis.

5. Differentially expressed proteins were defined using both:
   - Benjamini–Hochberg FDR < 0.05
   - Absolute log2 fold change > 0.26

6. Generalized estimating equations were used to account for repeated
   measurements within participants in the crossover design.

7. For between-diet comparisons, postprandial log2 fold changes were compared
   across dietary exposures. The area under the curve of postprandial log2 fold
   changes was calculated using the trapezoidal rule where indicated.

8. Pathway enrichment analyses used human protein/gene annotations and were
   performed using the enrichment-analysis workflow described in the
   manuscript.

9. Urinary proteomic analyses are exploratory. Urinary samples were assigned
   to approximate postprandial time windows using a predefined nearest-time
   assignment strategy.

10. Exact input-file names and output-file names may depend on the local
    directory structure used by the authors. Users attempting to reproduce the
    analysis should inspect the path and file-name settings at the beginning
    of each script.

11. The scripts may require installation of R packages and access to the
    processed proteomics matrices and metadata files deposited in the public
    repository or data repository associated with the manuscript.

12. The publicly available repository contains the analysis code. The raw
    proteomics data, spectral library, and protein-level quantification
    matrices are deposited separately in the iProX repository under accession
    number IPX0009525002.
